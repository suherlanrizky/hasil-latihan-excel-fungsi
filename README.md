# hasil-latihan-excel-fungsi
Kumpulan hasil latihan Excel yang berisi studi kasus pengolahan data tiket, gaji, laporan harian, rental mobil, hingga perhitungan diskon dan bonus.  Repo ini ditujukan untuk pembelajaran fungsi Excel seperti VLOOKUP, HLOOKUP, INDEX-MATCH, IF, SUM, AVERAGE, dan lainnya.
